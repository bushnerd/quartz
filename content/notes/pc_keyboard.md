# 3. 轴体
- 茶轴
  万金油，力度小，但是又有段落感。
- 青轴
  不需要按到底就可以完成输入
  断断续续的输入的话会觉得，需要的力气比茶轴大
- 红轴
  轻、键程短，容易误按
- 黑轴
  重，力度要求大，适合游戏
# 4. 接口
- 无线2.4G
	- 罗技优联
	  可以接入多个支持优联技术的鼠标、键盘
	- 普通2.4G
	  只能接入一个设备，但是效果和优联一样
- 蓝牙
  现阶段基本不考虑，会有不稳定的情况出现
- USB
	- 一体式
	- 键线分离
	  以及分为多种接口，但是意义不大
# 5. 功能
- 音量调节
- 播放控制
- 要是能多几个旋钮，可以精准的控制，可以映射到飞行游戏里的一些飞控按钮上
# 6. 背光
从视觉上会笔记好，而且也不需要很亮，暗一点的灯感受会更好
# 7. 键帽
- 原厂高度
  CHERRY高度
- OEM
- DSA
  半高键帽，可能是最合适的
  所有的键帽高度都是一致的，大平胸键帽
- XDSA
  半高键帽，并且键帽凹进去的弧度更小
